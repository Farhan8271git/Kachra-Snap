# 🌿 Kachra-Snap

**Smart Waste Classifier App | SDG 15: Life on Land**

Kachra-Snap is a web application concept designed to help users identify waste categories and understand how to dispose of waste responsibly.

The project is currently under development. The UI and core application pages have been implemented, while AI model training and integration are still in progress.

## ✨ Current Features

- 📊 Dashboard with scan statistics and activity charts
- 📷 Scan page with image upload and camera interface
- 🕘 Scan history with saved results
- 📈 Analytics dashboard
- ♻️ Disposal Guide for different waste categories
- 🌐 Language selector
- 📱 Responsive UI with a green-and-white theme

## 🎯 Planned Waste Categories

- **E-Waste:** Electronic devices and accessories
- **Organic:** Food scraps and biodegradable waste
- **Recyclable:** Paper, cardboard, plastic, glass and metal

The final classification behavior will depend on the trained model and its validation results.

## 🌱 Project Goal

The goal is to build a simple, accessible waste-classification experience that encourages responsible waste segregation and provides useful disposal guidance.

## 📌 Current Focus

Improving the UI, preparing the classification pipeline, training a suitable model, and validating predictions on real-world images.
